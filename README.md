# GameProject1-PuzzleLoop

Game Name: __*Alumnus Paradox*__

Names: Jacqueline Kilcrease (*Producer*), Noah Gaziano (*Designer*), Matthew Reader (*Programmer*), Kourtney Grey-Ford (*Artist*)

## Instructions:
The player must navigate around the map and close 3 rifts. A 60 second timer will loop the player back to the start with their rift closure intact.

Rift 1 is tucked in an alley, blocked by debris that must be moved.

Rift 2 is stuck deep in enemy territory, so the player must avoid the robots to find and close the rift.

Rift 3 is blocked behind a door that is controled by a console. The player must solve the code for the door to open.

Once all 3 rifts are captured, the game is won.
If the player is hit by a bullet or the patrol robot, the game is lost.

## Theme
This game is dictated by a 60 second time loop that continously loops the player through time (while they are still alive, of course). When the player dies or whenever they complete the objective, the loop stops.

## GRADUATE REQUIREMENTS:
1.) Paths were used to dictate the patrol bot's patrol path. Functionality in the object is set so that multiple paths can be used for different bots.

2.) Spatial audio is used for the turret/patrol bot activation sounds, as well as the patrol bot's teleportation back to last known patrol spot.

3.) Shaders were used in both the lose screen as well as the looping effect when time fades towards the end of the loop.

4.) Views are used to restrict the player view.

5.) Object inheritance is used in the UI buttons as well as the rifts.

6.) Both the turret and patrol bots have their own state machines that adjust the behavior of the agent given different conditions (namely when the player enters and exits the agent's view).
